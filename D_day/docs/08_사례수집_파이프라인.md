# 유튜브 사례 수집 파이프라인

강의에 쓸 실제 사례를 유튜브 영상에서 찾는 방법입니다. 영상을 내려받지 않고 한국어 자막만 받아 텍스트로 바꾼 뒤, 사례가 나올 만한 구간을 골라 읽습니다. 이번 데모데이 준비에서 118편을 처리해 사례 카드 62장을 만들었습니다(`05_사례카드.md`).

## 흐름

1. `tools/sources.txt`에 영상·재생목록·채널 주소를 한 줄에 하나씩 적는다
2. Windows PowerShell에서 `tools/run_subs.ps1` 실행 → `subs/`에 자막(.vtt), `list.tsv`에 영상 목록
   - `yt-dlp.exe`가 같은 폴더에 있어야 함 ([공식 배포본](https://github.com/yt-dlp/yt-dlp/releases))
   - 실행: `powershell -ExecutionPolicy Bypass -File .\run_subs.ps1`
   - 화면이 몇 분 멈춰 보여도 정상
3. `python3 vtt2txt.py` → `txt/`에 시각이 붙은 텍스트 (자동 자막의 반복 줄 제거)
4. `python3 cases.py 1300 영상ID ...` → 사례 표지어(실제로, 작년에, 저희 회사, 퇴사, 실패, 숫자+단위 등)가 몰린 구간을 점수순으로 출력
5. `python3 rng.py 영상ID@03:00-07:30` → 지정 구간을 30초마다 시각을 붙여 출력해 읽기
6. 사례 카드에 장면 / 대가 / 구분 / 출처(시각 링크)로 기록

## 사례 카드 표기 원칙

- **실화:** 화자가 직접 겪었다고 말한 일
- **관찰:** 강사·컨설턴트가 현장에서 봤다고 말한 일
- **예시:** 화자가 설명용으로 든 가정 장면 → 강의에서 실화처럼 말하지 않는다
- 자동 자막이라 고유명사·숫자가 틀릴 수 있으므로 강의에 쓰기 전 해당 시각을 직접 듣고 확인한다
- 채널 대부분이 자사 서비스를 판매하므로 "○○ 채널에서 나온 이야기"로 출처를 밝힌다

## 올리지 않는 것

자막 원문과 변환 텍스트(`data/subs`, `data/txt`)는 영상 제작자의 저작물이라 저장소에 올리지 않습니다(`.gitignore`). 사례 카드에는 요약과 시각 링크만 남깁니다.
