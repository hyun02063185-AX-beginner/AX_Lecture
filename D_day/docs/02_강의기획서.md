# 강의 기획서 (초안)

Nov 6, 2026 · @현래

## 1. 과정 개요

재직자 대상 AX(AI 전환) 실무 과정입니다. 업무 정리와 업무 도구 전환을 먼저 하고, 그 위에서 AI를 활용하도록 설계했습니다.

| 항목 | 내용 |
| --- | --- |
| 과정명 | \[가제\] 업무 정리에서 AI 활용까지: 역할 기반 AX 실무 과정 |
| 교육 목적 | 흩어진 업무를 정리하고 업무 도구를 단계적으로 전환하여, AI를 실제 업무에 안전하게 활용하는 기반을 마련 |
| 교육 대상 | 사무직 재직자 (경영·행정·기획·데이터 업무), 비개발 직군 |
| 교육 시간 | 7시간(1회) / 14시간(2회) / 21시간(3회) 중 선택 |
| 교육 방식 | 강의 + 실습(실습·공유 비중 50% 이상), 가상 기업 역할 기반 실습 |
| 권장 인원 | \[협의\] |
| 교육 환경 | 14·21시간: 1인 1노트북 권장, 인터넷 연결 필수 / 7시간: 기기 없이 시연으로 진행 가능 |

## 2. 기획 배경

AI 도구를 도입하고 교육을 해도 실제 업무에서는 잘 쓰이지 않는 경우가 많습니다.

- 기업 교육 담당자의 절반 이상이 "교육 후 현업 적용이 어렵다"고 답했고, 주요 원인으로 수준 차이와 직무 맞춤 부족을 꼽음 (팀스파르타 HRD 담당자 조사)
- 생성형 AI를 도입한 기업의 95%가 손익 효과를 보지 못했고, 원인은 기술보다 업무 방식에 있었음 (MIT NANDA, 2025)
- 대부분의 기업이 역할과 업무 방식을 바꾸지 않은 채 도구만 도입함 (Deloitte, 2026: 84%)
- 업무가 메신저, 개인 파일, 담당자의 기억에 흩어져 있으면 AI도 활용할 수 없음. 담당자가 휴가를 가거나 자리를 옮기면 업무가 멈추는 일도 흔함
- 사람마다 정보를 정리하는 방식이 다르다는 것은 40년 가까이 연구된 주제이며(개인 정보 관리 연구), 직장인은 하루의 약 27%를 정보 찾기에 쓴다고 응답함 (Microsoft, 2023)
- 실무의 한 단계만 AI로 바꾸고 보고·결재는 기존 방식으로 두면 일이 두 번이 되어 정착하지 못함 (초거대AI추진협의회 AX 사례집: 문서 입력 처리가 병목)

따라서 본 과정은 AI 도구 사용법보다 **업무를 정리하고, AI에 요청하고, 결과를 점검하는 일하는 방식**을 실습으로 익히는 데 중점을 둡니다. 업무 개선은 경영진의 지시가 아니라 직원의 업무 효율에서 출발할 때 정착된다는 관점입니다.

## 3. 교육 목표

과정을 마친 수강생은 다음을 할 수 있습니다.

| 목표 | 해당 과정 |
| --- | --- |
| 업무 정보가 흩어지는 원인을 이해하고, 팀이 지킬 최소한의 정리 규칙을 정한다 | 7·14·21시간 |
| 업무 도구를 개인 파일 → 공동 편집 → 업무 데이터 연결 단계로 전환하는 계획을 세운다 | 7·14·21시간 |
| 하나의 업무를 처음부터 끝까지 AI와 함께 처리하고, 사람이 확인할 지점을 정한다 | 14·21시간 |
| 업무 기록에서 바로 보고를 만들고, 보고·결재 과정의 개선안을 제안한다 | 21시간 |

## 4. 과정 특징

| 특징 | 내용 |
| --- | --- |
| 업무 전체 흐름 적용 | 업무의 한 단계가 아니라 처리부터 완료, 보고·결재까지 이어서 실습. 한 단계만 바꾸면 이중 작업이 되어 정착하지 못하기 때문 |
| 역할 기반 실습 | 수강생 전원이 가상 기업(직원 5명 온라인 판매 회사)의 대표 역할을 맡아 실습. 대표로서 효율적인 보고를 직접 받아 봄. 공공기관은 신설 TF 팀장 역할 |
| 회사 자료 없이 안전한 실습 | 강사가 준비한 가상 데이터로 실습. 실제 업무에서 자주 생기는 오류를 일부러 넣어 확인 습관을 익힘. 사내 자료 유출 걱정 없이 무료 AI로도 진행 가능 |
| 실제 사례와 연구 근거 | 국내 기업·기관의 도입 성공·실패 사례와 정보 관리 연구를 출처와 함께 제시 |
| 현업 적용 과제 | 회차 사이에 본인 업무에 적용하는 과제 (14·21시간) |
| 사내 환경 맞춤 | MS365 우선, 구글 워크스페이스는 대안으로 제시. 외부 AI 차단 / 사내 AI / 허용 환경별 활용 방법 제공 |
| 발언 부담을 줄인 참여 | 익명 의견 공유, 개인 → 짝 → 조 순서의 공유, 보기 선택 방식으로 직급·부서에 관계없이 참여 |
| 성과 보고 | 참석률·만족도에 더해 실습 제출률과 현업 과제 제출률 보고 |

## 5. 과정 구성

회차는 7시간씩 쌓입니다. 한 회차는 7차시(50분 강의·실습 + 10분 휴식)입니다.

| 과정 | 구성 | 실습 | 주요 결과물 |
| --- | --- | --- | --- |
| 7시간 | 1회차 | 권장 (시연으로 대체 가능) | 업무 정리 규칙, 공동 편집 자료, 업무 흐름도 |
| 14시간 | 1·2회차 | 필수 | + AI 업무 요청서, 결과 점검표, AI 적용 업무 흐름도 |
| 21시간 | 1\~3회차 | 필수 | + 기록 기반 보고서, 팀 AI 사용 규칙, 업무 개선안 |

### 1회차: 정보 정리와 업무 도구 전환

| 차시 | 주제 | 내용 | 방식 |
| --- | --- | --- | --- |
| 1 | 과정 소개와 역할 부여 | 과정 목표, 가상 기업 대표 역할, 담당자 부재 시 업무 공백 사례, 본인 업무 간단 점검 | 강의 + 참여 |
| 2 | 사람마다 다른 정보 정리 방식 | 같은 자료 20건을 각자 폴더로 정리한 뒤 서로 비교 | 개별 실습 + 짝 |
| 3 | 다른 사람의 자료에서 찾기 | 동료가 정리한 폴더에서 자료 찾기, 걸린 시간 비교 | 짝 실습 |
| 4 | 정보 정리의 기준 | 분류·태그·용어 통일·원본 관리 원칙 소개(정보조직론, 지식경영) → 조별 공통 규칙 3가지 정하기 | 강의 + 조별 |
| 5 | 업무 도구 단계별 전환 | 개인 파일 → 공동 편집(엑셀 온라인·원드라이브) → 업무 데이터 연결(쉐어포인트 리스트), 정한 규칙 적용 (대안: 구글 시트·노션) | 실습 또는 시연 |
| 6 | AI 검색 비교와 도입 계획 | 정리 전·후 자료에 AI로 같은 질문을 해 결과 비교, 도구 도입 실패 사례 → 도입 계획 1장 | 실습·시연 + 익명 선택 + 조별 |
| 7 | 업무 흐름도 작성과 정리 | 주문 접수부터 고객 안내까지 업무 흐름도 작성, 정보가 끊기는 지점 표시, 현업 과제 안내 | 실습 + 정리 |

### 2회차: 업무 흐름 전체에 AI 적용

| 차시 | 주제 | 내용 | 방식 |
| --- | --- | --- | --- |
| 1 | 현업 과제 공유 | 본인 업무 기록 결과 공유 | 익명 공유 + 짝 |
| 2 | AI의 특성과 업무 요청 방법 | 알려 준 정보만 활용하고 틀린 내용도 확신 있게 답하는 특성, 업무 요청서 4항목(목적·자료·기준·완료 형태), 결과 점검표 | 강의 + 시연 |
| 3 | 주문 접수 | 메신저·메일로 들어온 주문 15건을 AI로 주문표 정리 (주소 누락·수량 불분명·중복 주문 포함) | 개별 실습 |
| 4 | 재고 확인 | 주문표와 재고 자료를 대조해 출고 가능·부족 목록 작성, 점검표로 검증 (품목명 불일치 포함) | 개별 실습 |
| 5 | 고객 안내 | 출고·지연 안내문 초안 작성과 사람 확인, 무료·유료 AI 결과 비교 | 조별 실습 |
| 6 | 업무 흐름 전체 처리 | 신규 주문 5건을 접수부터 안내까지 처리, AI 처리 단계와 사람 확인 지점 표시, 사내 AI 환경별 적용 범위 확인 | 개별 실습 + 익명 선택 |
| 7 | 정리와 현업 과제 안내 | 처리 시간·오류 수 전후 비교, 본인 업무 흐름 작성, 과제 안내 | 정리 |

### 3회차: 보고·결재까지 연결

| 차시 | 주제 | 내용 | 방식 |
| --- | --- | --- | --- |
| 1 | 현업 과제 공유 | 본인 업무 AI 적용 결과 공유 | 익명 공유 + 짝 |
| 2 | 보고가 이중 업무가 되는 이유 | 업무는 시스템에서, 보고는 별도 문서로 다시 작성하는 문제와 개선 사례 | 강의 |
| 3 | 업무 기록 기반 보고 | 2회차 처리 기록에서 AI로 주간 보고 1장 작성, 숫자는 원자료와 대조 | 개별 실습 |
| 4 | 역할 교대 결재 | 담당자·팀장·대표 역할을 바꿔 가며 기존 방식 보고와 기록 기반 보고를 받아 결정, 결정 시간과 질문 수 비교 | 조별 역할 실습 |
| 5 | 우리 조직 결재 라인 점검 | 문서 양식·대면 보고·전자결재 중 개선 가능한 부분 선택, 팀 AI 사용 규칙 초안 | 익명 선택 + 조별 |
| 6 | 업무 개선안 발표 | 업무 흐름도와 전후 비교 수치로 경영진 보고 형식 5분 발표 | 발표 |
| 7 | 정리와 현업 적용 계획 | 본인 조직의 업무 흐름 하나와 첫 개선 단계 1장 | 정리 |

## 6. 실습 운영 방식

1. 7시간 단건 과정에 한해 실습을 강사 시연으로 대체할 수 있습니다. 시연이 어려운 환경은 영상으로 대신합니다.
2. 14·21시간 과정은 실습이 필수이며, 실습 환경(기기·인터넷)의 제공이 필요합니다.
3. 개별 실습을 기본으로 하고, 환경에 따라 조별 실습으로 대체합니다.
4. 실습 결과물은 제출합니다. 점수는 매기지 않고, 참여 여부를 교육 결과 보고에 반영합니다.

| 방식 | 조건 | 적용 과정 |
| --- | --- | --- |
| 개별 실습 (기본) | 1인 1기기 | 7·14·21시간 |
| 조별 실습 (대체) | 조별 기기 1대 | 7·14·21시간 |
| 강사 시연·영상 | 기기 없음 | 7시간 단건만 |

수업 중 실습은 모두 가상 데이터로 진행하므로 사내 자료가 필요하지 않습니다.

## 7. 과제와 성과 보고

수업은 가상 기업으로, 현업 과제는 본인 업무로 진행합니다. 현업 과제는 회사 정보를 제외한 요약만 제출합니다.

| 시점 | 현업 과제 |
| --- | --- |
| 1회차 후 | 본인 업무 중 하나를 골라 처리 방법을 기록하고, 정리 원칙 두 가지를 실제 자료에 적용 |
| 2회차 후 | 본인 업무 흐름 하나를 처음부터 끝까지 그리고, AI를 적용할 단계 한 곳을 실제로 처리해 점검표로 확인 |
| 과정 종료 2주 후 | 개선 결과물과 제안서 1장 (절감 시간 × 횟수 대비 비용, 데이터 보호 조건) |

**교육 결과 보고 항목:** 참석률, 만족도, 실습 제출률, 현업 과제 제출률 (2주 후)
