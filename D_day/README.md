## 과정 한눈에

- **역할 기반 실습:** 수강생은 "직원 5명 스타트업 CEO"(공공기관은 신설 TF 팀장)로 가상 기업 데이터를 가지고 실습
- **1회차 (7시간):** 정보 정리와 업무 도구 전환(DX) — 사람마다 다른 정리 방식, 최소 공통 기준, 도구 사다리, AI 검색 비교
- **2회차 (14시간):** 업무 흐름 끝까지 AI 적용(가로) — 주문 접수 → 재고 확인 → 고객 안내
- **3회차 (21시간):** 보고·결재까지 연결(세로) — 기록 기반 보고, 역할 교대 결재, 개선안 발표
