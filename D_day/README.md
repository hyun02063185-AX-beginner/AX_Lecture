# D_day — 유튜브 사례 수집 도구

강의에 쓸 실제 사례를 유튜브 영상에서 찾는 도구입니다. 영상을 내려받지 않고 한국어 자막만 받아 텍스트로 바꾼 뒤, 사례가 나올 만한 구간을 골라 읽습니다. 2026 AX 전문강사 데모데이 준비 때 만들어 영상 118편에서 사례 62장을 뽑았습니다.

- 사용법: [사례 수집 파이프라인](docs/08_사례수집_파이프라인.md)
- 스크립트: [`tools/`](tools/) — `run_subs.ps1`(자막 수집), `vtt2txt.py`(자막 → 텍스트), `cases.py`(사례 구간 점수), `rng.py`(구간 읽기)
- 로컬 `D_day/data/`(자막 원문, yt-dlp.exe)는 올리지 않습니다.
